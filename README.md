# 八字紫微解读 Skill

这是一个用于 Codex 的本地 skill，名称为：

```text
$bazi-ziwei-reading
```

它会根据八字问真排盘截图、性别、出生地等信息，组织一套八字与紫微斗数咨询流程。重点不是直接给出绝对结论，而是先做命盘读取和性格特征核对，再进入用神、忌神、格局、大运、事业、财富、感情、健康和 2026 离火年分析。

## 使用场景

适合在这些情况下调用：

- 想根据八字问真排盘截图看运程。
- 想生成一套可复制给 DeepSeek、Gemini 或 ChatGPT 的命理提问流程。
- 想先验证 AI 对命盘的读取是否准确，避免直接瞎编。
- 想围绕事业、财富、姻缘、家庭、个人特质、健康做综合分析。
- 想单独分析 2026 离火年对自己的影响。

## 调用方式

最稳的调用方式是直接写出 skill 名称：

```text
调用 $bazi-ziwei-reading，帮我看一下运程。
```

也可以这样说：

```text
用八字紫微解读 skill，帮我根据排盘截图做分析。
```

如果还没有排盘截图，skill 会先让你去这里在线排盘：

[八字问真网页版](https://pcbz.iwzwh.com/#/paipan/index)

排好后，需要补充：

- 排盘截图
- 性别
- 出生地
- 出生时间是否确定

## 标准流程

### 1. 在线排盘

先使用八字问真 app 或网页版排盘，确保截图里能看到四柱、十神、藏干、大运等信息。

### 2. 上传截图和基础信息

示例：

```text
调用 $bazi-ziwei-reading。
这是我的八字问真排盘截图。
性别：男
出生地：杭州
出生时间：确定
先帮我核对性格特征，不要直接下结论。
```

### 3. 先做交叉验证

skill 会先根据命盘描述性格、行为模式、家庭氛围、工作习惯、人际风格等，让用户核对匹配度。

这一步用于确认：

- 截图读取是否准确
- 命盘方向是否偏了
- AI 是否出现硬编或过度发挥

### 4. 基础分析

确认匹配度后，再继续分析：

- 用神和忌神
- 格局是否成立
- 核心优势和短板
- 大运走势
- 哪些阶段适合突破
- 哪些阶段需要稳扎稳打

### 5. 进阶分析

后续可以继续追问：

- 命盘里隐藏的天赋
- 当前人生课题
- 更容易遇到好运的场景和领域
- 适合上班、创业还是副业
- 能长期改善状态的小习惯

### 6. 2026 离火年分析

如果用户问 2026 年，skill 会围绕离火年继续分析：

- 如何借势搞事业
- 如何攒钱和拓展社交
- 火运对命盘的核心影响
- 适合尝试的方向
- 需要谨慎或避免的事情

## 输出风格

这个 skill 的输出原则是：

- 用大白话，不写玄乎难懂的话。
- 先核对，再深入分析。
- 明确区分命理推演和已验证事实。
- 避免使用“一定”“必然”“注定”这类绝对表达。
- 健康相关内容只做生活方式层面的提醒，不替代医生建议。
- 财务、婚姻、事业等重大选择只作为参考，不作为保证。
